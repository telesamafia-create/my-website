01 / WHAT IT IS

Search SoundCloud for tracks, albums and playlists. Import public Spotify metadata and find a playable match. Read lyrics through LRCLIB. Keep favourites separate from the library, export the library as JSON, and move through queue, history, shuffle and repeat without leaving the keyboard.

V.
02 / FEATURES

Everything
inside the player.

SEARCH
01

Search and play

Look through SoundCloud for tracks, albums and playlists. Spotify imports bring in public metadata, and Villife resolves each imported track to something you can actually hear.

YOUR
FAVORITES
02

Favourites and library

Keep favourites apart from the main library, import or export the whole collection as JSON, switch between light and dark themes, and set the volume once: it is remembered.

QUEUE
03

Queue and history

Line up what plays next, shuffle the queue, repeat one track and jump back through your listening history with keyboard shortcuts, a sleep timer and optional crossfade.

03 / WINDOWS

It behaves like
a Windows app.

Media keys control playback from any window, the system tray holds previous, play, pause, next and quit, and Discord Rich Presence shows the current track. The interface is a WebView2 window, so it looks native and stays out of the way.

04 / DETAILS

Your data stays
on your machine.

The library, favourites, history and settings are stored in the local WebView2 profile of your own computer. Nothing is uploaded and there is no account to create. The project is open source and the Windows build is published on GitHub.
